## Phase 1: Foundation (Tasks 1–4)

### Task 1: Session DB Schema Upgrade
**Subsystem:** L (Session Management)
**Port from:** `hermes_state.py` (6,322 LOC) — schema + migration + repair
**Modify:** `src/niaharness/services/session_db.py`
**What to do:**
- Replace 12-column `sessions` table with 45-column Hermes schema (add: source, user_id, session_key, input_tokens, output_tokens, cache_read_tokens, cache_write_tokens, tool_call_count, estimated_cost_usd, system_prompt, etc.)
- Replace 7-column `messages` table with 18-column Hermes schema (add: tool_call_id, tool_calls, tool_name, token_count, finish_reason, reasoning, etc.)
- Port `_reconcile_columns()` — declarative schema migration (in-memory SCHEMA_SQL parse + ALTER TABLE ADD COLUMN on diff)
- Port `repair_state_db_schema()` + `_claim_repair_attempt()` + `_db_opens_cleanly()` — replaces data-losing rename-and-reinit
- Port `_execute_write()` with BEGIN IMMEDIATE + jitter retry
- Add trigram FTS5 virtual table for CJK substring search
- Delete `session_storage.py` JSON snapshots — route --continue/--resume through SQLite
**Unlocks:** Real per-token cost tracking (Task 5), cron output persistence (Task 11), doctor FTS-repair (Task 10), multi-platform session attribution
